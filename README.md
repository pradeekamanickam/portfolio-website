Local preview:

Run a simple static server from the project root and open http://localhost:8000

Python 3:
```bash
cd PORTFOLIO01
python3 -m http.server 8000
```

Files:
- index.html — landing page
- about.html — education & objective
- projects.html — project details
- contact.html — accessible contact form

- js/script.js — accessible form feedback
